## 1. 概述

###  业务目标

发票模块分为 **四个子模块**，形成「基础数据 → 配置 → 手动/自动开票 → 百望开票与交付」的完整链路：

| 模块 | 名称 | 核心职责 |
|------|------|----------|
| 一 | 公司管理 | 维护开票方、收票方基础信息（税号、地址、银行账号等） |
| 二 | 发票配置 | 维护发票类型、税率、开票模板、关联客户单位等规则 |
| 三 | 手动开票 | 人工选择配置 + 开票方 + 收票方，走申请→查询→交付→冲红流程 |
| 四 | 自动开票 | 关联客户单位、收票方、开票方、配置，按业务批量生成并开具发票 |

###  技术架构
    
InvoiceCompanyController，InvoiceCompanyService (开票方和收票方基础信息)
InvoiceConfigController，InvoiceConfigService   (开票配置)       
InvoiceController InvoiceService   (操作开票申请 )  

LZ.ApiService中 BaiWangService（百望发票旗舰版开放平台：申请开票 / 查询申请 / 查询发票 / 交付接口 ）



## 2. 公司管理

### 功能说明

统一管理可用于开票的公司主体信息。一张发票通过 `IssuerUnitID`（开票方）和 `RecipientUnitID`（收票方）关联到 `Live_InvoiceCompany` 记录。
`Live_InvoiceCompany`中记录了所有公司主体的税号，交付邮箱，联系方式
公司管理按人力公司做区分

### 数据模型

**表：`Live_InvoiceCompany`**

| 字段 | 类型 | 说明 |
|------|------|------|
| ID | Guid | 主键 |
| CompanyID | string | 人力公司 |
| Name | string | 公司名称 |
| TaxNo | string | 统一社会信用代码 / 税号 |
| LegalPerson | string | 法人 |
| Address | string | 地址 |
| Phone | string | 电话 |
| Bank | string | 开户行 |
| BankNo | string | 银行账号 |
| IsEnabled | bool | 是否启用 |
| CreateTime | DateTime | 创建时间 |
| UserID | int | 创建人 |
| Eamil | string | 交付邮箱 |



### 业务规则

1. 公司名称不可重复（Add 时已校验）
2. 禁用公司（`IsEnabled=false`）不可在新发票中选择
3. 开票方税号必须与百望平台注册销方一致


## 3. 发票配置

### 3.1 功能说明

发票配置定义「怎么开」：发票类型、业务模板、税率、是否含工资/服务费等。可关联客户单位，供自动开票和手动开票引用。

### 3.2 数据模型

**表：`Live_InvoiceConfig`**

| 字段 | 类型 | 说明 |
| ID | Guid | 主键 |
| Title | string | 配置名称 |
| InvoiceTitle | string | 发票抬头 |
| InvoiceType | InvoiceTypeEnumType | 发票类型 |
| PrintTemplate | PrintTemplateEnumType | 业务模板（外部发票/内部发票等） |
| IsIncludeSalary | bool | 是否含工资 |
| IsIncludeServiceFee | bool | 是否含服务费 |
| TaxPointSalaryValueAdded | decimal | 工资增值税率 |
| TaxPointSalaryAdditional | decimal | 工资附加税率 |
| TaxPointServiceFeeValueAdded | decimal | 服务费增值税率 |
| TaxPointServiceFeeAdditional | decimal | 服务费附加税率 |
| IsEnabled | bool | 是否启用 |



// 发票类型 InvoiceTypeEnumType （需要重新配置发票类型）
SpecialInvoice = 0      // 增值税专用发票
CommonInvoice = 1       // 增值税普通发票
ECommonInvoice = 2      // 增值税电子普通发票
ESpecialInvoice = 3     // 增值税电子专用发票


## 4. 模块三：手动开票

### 4.1 功能说明

操作人员手动创建发票申请，选择：

1. **发票配置**（类型、税率规则）
2. **开票方**（IssuerUnitID → Live_InvoiceCompany）
3. **收票方**（RecipientUnitID → Live_InvoiceCompany）
4. **开票明细**（TaxRecords）



### 4.4 手动开票完整流程（含百望）

创建发票申请 =>  开具发票 => 交付发票 （发网址链接到邮箱，打开网址后可下载发票）
已开具发票 => 快捷冲红 => 交付冲红发票


## 5. 模块四：自动开票

### 5.1 功能说明

在业务场景（如企业工资发放、结算完成）中，系统根据 **客户单位 + 发票配置 + 开票方 + 收票方** 自动生成发票记录，支持批量为客户单位开具发票。

### 5.2 关联关系

```
客户单位 (CustomerGID)
    │
    ├── 发票配置
    ├── 收票方信息
    └── 开票方信息
```



**逻辑摘要：**

1. 读取客户单位关联的 `Live_InvoiceConfig`
2. 按配置生成 `Live_InvoiceExtension` 列表
3. 关联开票方信息，关联收票方信息




## 6. 百望接口对接

### 6.1 已实现（BaiWangService）

| 方法 | 百望 API | 用途 |
|------|----------|------|
| `AddPreInvoiceAsync` | `baiwang.output.preinvoice.add` | 创建开票申请 |
| `QueryPreInvoiceAsync` | `baiwang.output.preinvoice.query` | 查询开票申请 |
| `QueryInvoiceAsync` | `baiwang.output.invoice.query` | 查询已开发票 |

**代码位置：**

- 接口：`Services/LZ.ApiService/Interface/IBaiWangService.cs`
- 实现：`Services/LZ.ApiService/Services/BaiWangService.cs`
- 签名：`Services/LZ.ApiService/Helper/BaiWangHelper.cs`
- 配置：`Common/LZ.Model/Options/BaiWangOption.cs`
- 模型：`Common/LZ.Model/BaiWangModel/`
